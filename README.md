# DoorMarket — лабораторная работа № 10

Информационный каталог салона дверей. Три категории (межкомнатные, входные, раздвижные), по пять моделей в каждой. У категории есть страница со списком, у модели — подробная карточка. Добавлять категории и товары может только администратор.

## Страницы

| Адрес | Что это |
| --- | --- |
| `/catalog` | список категорий |
| `/catalog/items?id=2` | модели категории |
| `/catalog/item?id=6` | подробное описание модели |
| `/admin/category` | новая категория |
| `/admin/item` | новый товар |
| `/vhod` | вход администратора |

Логин демонстрационного администратора: `admin`, пароль `admin123`.

## Где код лабораторной

- `src/lib/catalog.ts` — категории, товары, сохранение новых записей
- `src/lib/session.ts` — вход администратора
- `src/routes/catalog/` — каталог, список и карточка
- `src/routes/admin/` — формы добавления
- `src/components/site-shell.tsx` — меню, пункты администратора скрыты от гостя
- `public/media/products/` — фотографии дверей
- `Otchet_kod_DoorMarket.docx` — отчёт: что в каком файле

Новые записи хранятся в браузере (`localStorage`), стартовые пятнадцать моделей записаны в коде.

## Запуск

```bash
npm install
npm run dev
```
